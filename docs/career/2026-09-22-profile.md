# 秋招项目卡｜二手车价格预测

核验日：2026-09-22；材料编号：P10。

## 岗位标签
Data Science · Data Analytics · Business Analytics · Applied Machine Learning · Feature Engineering

## 项目描述
将混合单位和不规则车辆报价转换为可建模数据，包含缺失、重复及异常处理，EDA，车龄里程和功率重量特征，线性回归与随机森林比较，以及清洗数据、指标和模型文件导出。

## 推荐展示
数据质量问题如何转成清洗规则；特征设计的业务含义；透明基线与非线性模型的取舍；训练、评估与产物的可复用性。数据科学/商业分析岗位优先，纯品牌岗位一般不占主要篇幅。
